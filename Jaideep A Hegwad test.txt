2) Constructor is a special type of method whose name is same as className and does not contain any return type and is used to initialize the variables of the class, helps in code reusability. there are two type of constructors i.e default constructor which has no parameters and initializes the variables with their default values and a parameterized constructor which accepts arguments that will be initialized to the variables.

3)  this keyword is used to solve ambiguity problem where the names of the instance variable and the parameter is same and to differentiate the instance variables of the class from any other variables. Whereas this() is used in constructor chaining and it is always used in the first line of the constructor. this() invokes a constructor of the same class. it is used to access one constructor from another.

4) the signature of main method is inbuilt in java we cannot change the signature except the parameter, however main has to be static because it allows jvm to access main method directly without creating any instances as main is the start point and end point of any program execution. there are two types of methods static and non-static methods, static methods can be accessed without creating any class instances and the should be accessed using the classname and dot operator whereas non-static methods should be accessed through instance of a class and it cannot be accessed directly
